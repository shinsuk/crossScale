# CrossScale (크로스스케일)

CrossScale은 웹페이지 내에 등장하는 큰 숫자(한국어 '조, 억, 만' 및 영어 '$ B, M, T')를 실시간으로 감지하고, 상대 국가의 단위 및 실시간 환율을 적용하여 툴팁으로 직관적으로 보여주는 Chrome 확장 프로그램입니다.

## ✨ 주요 기능

- **자동 패턴 인식:** "6조 9,116억원", "$450B" 같은 숫자를 감지해 자동으로 밑줄로 강조합니다.
- **크로스 노드 하이라이팅:** 숫자가 여러 HTML 태그(`<em>`, `<span>` 등)에 분리되어 있어도 문맥을 이해하여 하나의 덩어리로 정확히 인식합니다.
- **양방향 환산 및 포맷팅:**
  - 한국어 단위(원) -> 미국식 단위(달러, B/T 등)로 환산
  - 미국식 단위(달러) -> 한국식 단위(원, 조/억/만)로 환산
- **실시간 환율 연동:** 백그라운드에서 매시간 환율 API를 호출하여 최신 환율을 반영합니다.
- **고정 환율 설정:** 확장 프로그램 팝업 UI를 통해 사용자가 원하는 고정 환율을 직접 입력하여 사용할 수 있습니다.
- **듀얼 복사 기능 지원 툴팁 UI:** 마우스 호버 시 화면 밖으로 잘리지 않는 스마트 툴팁이 나타납니다. 원본 기본 수치와 환산된 수치를 각각 버튼 한 번으로 클립보드에 복사할 수 있습니다.

## 🚀 설치 방법

1. 이 저장소를 로컬 컴퓨터에 클론하거나 ZIP 파일로 다운로드하여 압축을 풉니다.
   ```bash
   git clone https://github.com/yourusername/crossScale.git
   ```
2. 크롬 브라우저를 열고 주소창에 `chrome://extensions/`를 입력하여 접속합니다.
3. 우측 상단의 **'개발자 모드'** 토글을 켭니다.
4. 좌측 상단의 **'압축해제된 확장 프로그램을 로드합니다'** 버튼을 클릭합니다.
5. 소스코드가 있는 `crossScale` 폴더를 선택합니다.

## 🛠 기술 스택

- **Manifest V3:** 최신 Chrome Extension API 사용
- **Vanilla JS & CSS:** 외부 라이브러리 의존성 없이 가볍고 빠른 성능
- **MutationObserver & Debounce:** 무한 스크롤 및 동적 댓글 렌더링 환경 완벽 대응 및 성능 최적화
- **Block-Level DOM Traversal (v1.8+):** 복잡하게 쪼개진 DOM 구조에서도 블록 태그(`<td>`, `<li>` 등) 단위로 문맥을 논리적으로 병합하여 정규식 스캔 및 분할 하이라이팅 수행

## ⚙️ 설정 및 사용법

확장 프로그램 아이콘을 클릭하면 설정 팝업이 나타납니다.
- **기능 켜기/끄기:** 확장 프로그램이 불필요한 페이지에서는 스위치 하나로 즉시 기능을 끌 수 있습니다.
- **예외 URL 설정:** 설정 팝업에서 특정 URL을 등록하면, 해당 URL로 시작하는 웹페이지에서는 숫자를 인식하지 않습니다. '현재 페이지 추가' 버튼으로 클릭 한 번에 예외 목록에 등록할 수 있습니다.
- **고정 환율 사용:** 특정 환율을 기준으로 계산하고 싶다면 활성화 후 숫자를 입력하세요. (예: 1달러 = 1350원)
- 하단 상태 메시지에서 현재 적용되고 있는 최신 API 실시간 환율을 실시간으로 확인할 수 있습니다.

## 💡 주요 문제 해결 기법 (Troubleshooting)

기존의 텍스트 노드 탐색 방식은 숫자와 단위가 다른 태그로 찢어져 있거나(예: `<em>6조</em> 억원`), 웹페이지 구조 특성상 하나의 셀 안에 수많은 줄바꿈과 탭(`\n\t\t\t`)이 존재하는 경우 계산을 누락하거나 오작동(다른 문단의 단위를 끌어다 씀)하는 한계가 있었습니다.

CrossScale은 **Block-Level DOM Grouping** 알고리즘을 도입하여, 전체 문서가 아닌 `<td>`, `<p>`, `<li>` 등 문단과 표를 구분하는 블록 단위로 텍스트를 논리적으로 묶어냅니다. 이를 통해 서로 다른 문단에 위치한 문자가 병합되는 치명적 오작동을 차단함과 동시에, 아무리 많은 엔터와 공백이 있어도 같은 블록 내에 있다면 정확히 문맥을 이어붙여 한 치의 오차 없이 숫자를 인식합니다. 

- **CSS 충돌 방지 및 레이아웃 보호:** 기존 웹사이트(네이버 금융 등)에 정의된 `span` 태그 스타일(예: `float: right`, `display: block`)이 확장 프로그램이 삽입하는 하이라이팅 태그에 전이되어 레이아웃이 깨지는 현상(스타일 오염)을 방지하기 위해, `.crossscale-highlight`에 강력한 CSS 초기화(`!important`, `float: none`, `margin: 0` 등)를 적용하여 시각적 안정성을 확보했습니다.
- **SPA(Single Page Application) 완벽 호환 (v1.12+):** YouTube와 같이 Polymer, React 등으로 구축된 SPA 환경에서 발생하는 DOM 갱신 충돌(예: 영상 제목 겹침 현상)을 방지합니다. 기존 텍스트 노드를 파괴하는 대신 `nodeValue`를 투명하게 비워 SPA 프레임워크가 추적할 수 있게 유지하고, `MutationObserver`를 통해 SPA의 렌더링 주기에 맞춰 주입된 하이라이트 노드를 자동으로 정리(Garbage Collection)하는 우회 기법을 적용했습니다.
